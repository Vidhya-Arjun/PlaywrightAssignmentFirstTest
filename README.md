A short note on difference between playwright package and @playwright/test
    A playwright package contains web interaction element where as @playwright/test includes Test Runner along with web element interaction.
    For example : Using playwright package we can interact with page where as using @playwright/test we can assert using expect , execute test in parallel, we can setup and teardown etc..
